Remarks

The type of the array (integer or real) is determined during initialization. The array supports operations to get and set values at specific row and column indices, as well as metadata about its dimensions and type. The array must be initialized and compiled before it can be used.

Set(StoredProgram, string)

Configures the array declaration by parsing the provided parameters.

public override void Set(StoredProgram program, string parameters)

Parameters

program StoredProgram

The BOOSE.StoredProgram instance associated with this array declaration.

parameters string

A string containing the array declaration parameters in the format: "array <type> <name> <size>[,<dim>]".

Remarks

The parameters string must specify the array type (e.g., "int" or "real"), the variable name, and the size. An optional second dimension can be included, separated by a comma.

Exceptions

CommandException

Thrown if the parameters string does not contain at least three parts or does not conform to the expected format.
