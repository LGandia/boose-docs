Remarks

This class provides additional functionality for managing commands and methods, including the ability to add commands to the main program or to the body of a method, jump to specific execution points, and retrieve variables from the current call stack. It also integrates with an BOOSE.ICanvas for graphical operations.

Returns

Evaluation

An BOOSE.Evaluation object representing the value of the variable if it exists in the current call stack frame; otherwise, the value of the variable from the base context.

Remarks

This method first attempts to retrieve the variable from the local scope of the current call stack frame. If the variable is not found in the local scope, it falls back to retrieving the variable from the base context.

ResetProgram()

Resets the program state to its initial configuration.

public override void ResetProgram()

Remarks

This method clears all commands, methods, and the call stack, resets the current method to null, and sets the next execution index to -1. It also invokes the base class implementation of ResetProgram() to ensure any additional base-level reset logic is applied.

Run()

Executes a sequence of commands in order, with support for modifying the execution flow.

public override void Run()

Remarks

The method processes commands sequentially from the beginning of the list. If a command modifies the execution flow by setting nextIndex to a non-negative value, the method jumps to the specified index in the command list. Otherwise, it proceeds to the next command in sequence.
