Unit tests for the PenCommand class. These tests verify that the command executes safely under a variety of parameter conditions, without throwing exceptions.

Because AppCanvas cannot be mocked or inspected safely, these tests focus solely on ensuring that PenCommand accepts parameters, resolves variables and expressions, and executes without runtime errors.
