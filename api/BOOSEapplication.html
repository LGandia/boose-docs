Classes

AppArray

Represents a two-dimensional array that can store either integer or real (double) values.

AppAssign

Represents an assignment command that evaluates an arithmetic expression and stores the result in a BOOSE variable.

AppBoolean

Represents a boolean variable within the BOOSE scripting system. Stored internally as 1 (true) or 0 (false) to match AppEvaluation.Value.

AppCall

Represents a method invocation command within the BOOSE application.

AppCall locates a method by name, evaluates its argument expressions, binds them to the method's parameters, executes the method body inside a new call frame, and finally stores the return value in the global variable table.

AppCanvas

Provides a drawing canvas that implements BOOSE library commands, shapes, text and error rendering

AppCommand

Represents a command that operates on an AppCanvas using parsed parameters. Implements the BOOSE.ICommand interface for BOOSE command execution.

AppCommandFactory

Factory class responsible for creating command instances based on string identifiers. Implements the BOOSE.ICommandFactory interface.

AppCommandOneParameter

Abstract base class for commands that require a single parameter. Implements the BOOSE.ICommand interface.

AppCommandTwoParameters

Abstract base class for commands that require two integer parameters Implements the BOOSE.ICommand interface from BOOSE library

AppEnd

Represents the terminating command for structured control blocks such as IF, WHILE, FOR, and METHOD within the BOOSE scripting system.

AppEnd is responsible for resolving block termination and determining whether execution should continue normally or jump back to the start of a loop construct.

The behaviour of this command depends on the Type value assigned during Set(StoredProgram, string):

  • if → no action; control simply exits the IF block.
  • while → jumps back to the matching WHILE if the loop condition was true.
  • for → jumps back to the matching FOR if the loop condition was true.
  • method → no-op under the direct-call execution model.
AppEvaluation

Represents a basic evaluation node within the BOOSE execution model.

AppEvaluation provides a minimal concrete implementation of BOOSE.Evaluation and BOOSE.IEvaluation, suitable for use as a variable or placeholder evaluation object within a stored program.

AppFor

Implements the FOR loop construct for the BOOSE scripting system.

AppFor handles loop initialization, iteration, condition checking, and early termination by jumping to the matching END FOR when the loop condition becomes false.

AppIf

Implements the IF conditional command for the BOOSE scripting system.

AppIf evaluates a comparison expression and conditionally executes or skips the associated IF block. When the condition is false, control flow jumps to the matching ELSE or END IF command.

AppInt

Represents an integer variable within the BOOSE scripting system.

AppInt supports literal assignment, simple multiplication expressions, and fallback evaluation through the BOOSE expression evaluator.

AppMethod

Represents a user-defined method within the BOOSE scripting system.

An AppMethod stores metadata about the method such as its name, return type, return variable, parameter list, and the sequence of commands that form the method body.

AppParser

Parses script lines into executable BOOSE BOOSE.ICommand objects.

The AppParser is responsible for:

  • Normalizing whitespace and removing invisible characters
  • Detecting control-flow constructs (IF, WHILE, FOR, METHOD)
  • Creating commands via an BOOSE.ICommandFactory
  • Assigning parameters and expressions to commands
  • Updating method definitions inside AppStoredProgram
AppPeek

Implements the PEEK command, which reads a value from an array and assigns it to a target evaluatable variable.

AppPoke

Implements the POKE command, which writes a value into a specific element of an AppArray at the given row and column.

AppReal

Represents a real (double‑precision) numeric variable within the BOOSE scripting system.

AppReal supports:

  • Literal assignment
  • Multiplication expressions (e.g., a * b * 3.5)
  • Fallback evaluation using the program's expression evaluator
  • Resolving values from other AppReal or AppInt variables
AppStoredProgram

Represents an application-specific stored program that extends the functionality of a base BOOSE.StoredProgram. This class manages a collection of commands, methods, and a call stack to support program execution and method invocation.

AppWhile

Implements the WHILE control‑flow command for the BOOSE scripting engine. A WHILE command evaluates a comparison expression and either:

  • enters the loop body if the condition is true
  • skips forward to the matching END WHILE if the condition is false
AppWrite

Implements the WRITE command for the BOOSE scripting engine. This command evaluates text or numeric expressions and writes the resulting string to the program's canvas.

CallFrame

Represents a single stack frame used during a method call in the BOOSE runtime. A CallFrame stores:

  • Local variables belonging to the method
  • The return address where execution should resume
  • The name of the return variable (usually the method name)
Circle

Implements the CIRCLE command for the BOOSE scripting engine. This command draws a circle at the current canvas position using a radius that may be a literal, a variable, or an expression.

DrawToCommand

Represents a command to draw a line to a specified point on the canvas. Inherits from AppCommandTwoParameters to utilize two parameters for the coordinates.

ErrorReport

Gets and shows error messages on the canvas, ensuring each message is shown only once. Provides static properties to set the canvas and target picture box for displaying errors. Displays error messages using the canvas's ShowError method and invalidates the picture box to trigger a repaint.

MoveToCommand

Represents a command to move the drawing cursor to a specified point on the canvas without drawing. Inherits from AppCommandTwoParameters to utilize two parameters for the coordinates.

NullCommand

A no‑operation command used as a safe fallback when an unknown or unrecognized command is encountered. This command intentionally performs no actions and ensures the program continues running without interruption.

PenCommand

Represents a command that sets the pen colour and width for drawing on the canvas. Inherits from BOOSE.CommandThreeParameters to support three RGB parameters, with an optional fourth parameter for pen width.

Rect

Represents a command that draws a rectangle on the canvas. The rectangle is always drawn unfilled. Inherits from AppCommandTwoParameters to support two parameters representing width and height.

booseInterface

Main Windows Form for the BOOSE application. Allows users to draw on a canvas using BOOSE commands in the PictureBox.
