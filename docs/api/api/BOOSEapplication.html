Table of Contents

Namespace BOOSEapplication

Classes

AppCanvas

Provides a drawing canvas that implements BOOSE library commands, shapes, text and error rendering

AppCommandFactory

Factory class responsible for creating command instances based on string identifiers. Implements the BOOSE.ICommandFactory interface.

AppCommandOneParameter

Abstract base class for commands that require a single integer parameter. Implements the BOOSE.ICommand interface.

AppCommandTwoParameters

Abstract base class for commands that require two integer parameters Implements the BOOSE.ICommand interface from BOOSE library

AppParser

Parser for application commands and programs. Implements the BOOSE.IParser interface.

AppStoredProgram

Represents a stored program within the application context. Extends the BOOSE.StoredProgram class from the BOOSE library.

Circle

Represents the CIRCLE command in the BOOSE application. Draws a circle with an unfilled circle with specified radius at the current position on the canvas. Inherits from AppCommandOneParameter and uses a single int as radius>.

DrawToCommand

Represents a command to draw a line to a specified point on the canvas. Inherits from AppCommandTwoParameters to utilize two parameters for the coordinates.

MoveToCommand

Represents a command to move the drawing cursor to a specified point on the canvas without drawing. Inherits from AppCommandTwoParameters to utilize two parameters for the coordinates.

PenCommand

Represents a command to set the pen color and width for drawing on the canvas. Inherits from BOOSE.CommandThreeParameters to utilize three parameters for RGB color values.

Rect

Represents a command to draw a rectangle on the canvas, filled and unfilled Inherits from AppCommandTwoParameters to utilize two parameters for width and height.
